# Faithful Backport

A Minecraft Forge mod that brings spear mechanics to Minecraft 1.20.1.

## Features

- **Wooden Spear**
- **Diamond Spear**
- **Netherite Spear**
- Custom spear attack and lunge mechanics
- Charge-based attacks
- Defensive bracing
- Custom first-person spear attack animation
- Custom sounds and item textures
- Spear crafting and smithing recipes
- Lunge enchantment

## Compatibility

| Requirement | Version |
|---|---|
| Minecraft | 1.20.1 |
| Mod Loader | Minecraft Forge |
| Forge | 47.4.28 |
| Java | 17 |

## Installation

1. Install Minecraft Forge 1.20.1.
2. Download the latest release from the [Releases](../../releases) page.
3. Place the downloaded JAR file into your Minecraft `mods` folder.
4. Launch Minecraft using the Forge profile.

## Development

This project was developed using Java 17 and the Minecraft Forge MDK.

To build the project locally:

```bash
./gradlew build
```

On Windows:

```powershell
.\gradlew.bat build
```

The compiled mod JAR will be located in `build/libs/`.
